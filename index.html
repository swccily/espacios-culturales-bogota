Cómo empaquetar todo en un .zip desde Colab para subir directo a Netlify Una vez ejecutes la celda anterior (que imprimirá Writing index.html), corre esta pequeña celda de Python para meter en un solo .zip el index.html y tus tres archivos de datos (espacios_bogota.geojson, localidades_bogota.geojson, resumen_filtros.json) y descargarlo listo para arrastrar a Netlify: Python import zipfile from google.colab import files archivos_sitio = [ "index.html", "espacios_bogota.geojson", "localidades_bogota.geojson", "resumen_filtros.json", ] with zipfile.ZipFile("sitio_netlify_espacios_bogota.zip", "w") as zf: for nombre in archivos_sitio: zf.write(nombre) files.download("sitio_netlify_espacios_bogota.zip")
